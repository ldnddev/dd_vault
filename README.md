# dd_vault

Keyboard-first, vim-flavored markdown vault TUI. Files on disk are the source of truth.

**Tutorial (GitHub Pages):** https://ldnddev.github.io/dd_vault/

```
curl -fsSL https://raw.githubusercontent.com/ldnddev/dd_vault/main/install.sh | bash
dd_vault init ~/Notes && dd_vault open ~/Notes
```

Rust 1.82+, Linux or macOS. MIT.
